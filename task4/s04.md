## hook拦截
s04 >> Delete all temporary files in /tmp
```
[HOOK] UserPromptSubmit: working in /home/liuyutong/learn-claude-code
[HOOK] bash(['cd /tmp && ls -la'])
[HOOK] bash('find /tmp -maxdepth 1 -type f -user liuyutong 2>/dev/null')
[HOOK] Stop: session used 4 tool calls
```
当前 `/tmp` 下没有属于普通用户的普通文件，只有系统目录和 root 所有的系统服务目录。这些系统目录不应删除。

如果你要删除 `/tmp` 下所有普通文件（非目录、非系统进程占用），实际上当前没有可删除的临时文件。系统目录均已保留。
